# How to Test AI Apps

This repository contains **all materials** for the *How to Test AI Apps*.

---
## Branch‑per‑Day layout 🗂️

**Each day lives in its own Git branch**:

| Branch | What you’ll find |
|--------|------------------|
| `day-01-ai-fundamentals-and-challenges` | Hands‑on prompt‑testing challenges (security, hallucination, bias, etc.). |
| `day-02-promptfoo-basics`              | Promptfoo installation & basics (prompts, providers, assertions/metrics). |

---
## How to use this repo

1. **Clone the code**

   ```bash
   git clone https://github.com/engenious-inc/how-to-test-ai.git
   cd how-to-test-ai
   ```

2. **Switch to the day you need**

   ```bash
   # Example: Day 1 materials
   git checkout day-01-ai-fundamentals-and-challenges

   # Example: Day 2 materials
   git checkout day-02-promptfoo-basics
   ```

   > Or use the *Branch* menu on GitHub to browse files without cloning.

3. **Open the day’s README**

   Every branch has its own `README.md` at the root that explains objectives, setup, and deliverables.

4. **Follow the instructions & have fun breaking—then fixing—LLMs!** 🚀
